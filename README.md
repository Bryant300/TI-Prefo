# TI de préformation — découverte du métier de développeur web

Projet réalisé par Bryan pendant sa préformation. Ce site statique présente un rapport d'entreprise consacré à Akis Studio, une interview, mon parcours et ma conclusion sur le métier de développeur web.

## Technologies

- HTML5
- CSS3

## Lancer le projet

Ouvrir `index.html` dans un navigateur. Aucun serveur, paquet ou base de données n'est nécessaire.

## Contenu

- Page d'accueil et navigation entre cinq pages
- Rapport de découverte d'entreprise
- Interview d'un professionnel du web
- Présentation du parcours et conclusion
- Liens vers le site et les réseaux d'Akis Studio
